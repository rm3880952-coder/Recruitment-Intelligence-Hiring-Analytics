# Recruitment Intelligence & Hiring Analytics

## Project Overview

An end-to-end Recruitment Intelligence & Hiring Analytics project designed to evaluate recruitment performance, hiring conversion, talent acquisition effectiveness, recruiter productivity, and recruitment cost efficiency using Microsoft Excel.

The project transforms recruitment data into structured analytical insights and an interactive dashboard to support data-driven HR and Talent Acquisition decision-making.

## Business Objectives

- Measure overall recruitment and hiring performance
- Analyse candidate conversion across the recruitment funnel
- Evaluate the effectiveness of different recruitment sources
- Compare hiring performance across departments and job levels
- Analyse recruiter-wise hiring outcomes
- Evaluate recruitment cost efficiency
- Identify patterns that can support better hiring decisions

## Analysis Areas

### Recruitment Funnel Analysis
Tracks candidate movement from application through screening, interview selection, final selection, offer acceptance, and joining.

### Source-wise Hiring Analysis
Compares recruitment sources including LinkedIn, Naukri, Indeed, and Employee Referral based on candidate volume and joining performance.

### Department-wise Hiring Analysis
Evaluates hiring outcomes across HR, Front Office, Finance, Housekeeping, Marketing, Sales, IT, Restaurant, Kitchen, and Engineering.

### Recruiter-wise Hiring Analysis
Compares recruiter performance based on candidate volume, joined candidates, and joining rate.

### Job Level-wise Hiring Analysis
Analyses hiring outcomes across Entry-Level, Mid-Level, and Senior-Level positions.

### Recruitment Cost Analysis
Evaluates total recruitment expenditure and average recruitment cost across key hiring stages.

## Dashboard

The Excel dashboard provides a consolidated view of:

- Recruitment KPIs
- Source-wise joining performance
- Department-wise hiring performance
- Recruitment funnel conversion
- Recruitment cost analysis
- Recruiter-wise hiring outcomes
